# Web Dev I – Lab Assignment 3: Responsive Personal Portfolio (CSS Advanced)

## Description
A one-page responsive portfolio built on the Lab 2 base and upgraded with modern CSS:
Flexbox (header, hero, form, footer), CSS Grid (skills and projects), media queries
(mobile-first), relative units (rem, em, %, vw, vh), hover effects with transitions,
CSS transforms, and keyframe animations (colour-changing "Full Stack Developer" text,
slide-in hero, fade-in sections, floating profile image).

Sections: Header, Hero, About, Skills, Projects, Contact, Footer.

## Files
- `index.html` – page structure
- `style.css` – all styling, commented
- `avatar.svg` – profile image (replace with your own photo)

## Steps to view responsive behavior
1. Open `index.html` in Chrome or Edge.
2. Press `F12` (or right-click → Inspect) and click the device toolbar icon (`Ctrl+Shift+M`).
3. Resize the viewport or pick a device and check each breakpoint.

## Breakpoints tested
| Screen | Width | Layout |
|---|---|---|
| Mobile | below 480px | 1-column grids, text above image in hero, stacked header/footer |
| Large phone | 480px+ | Skills in 2 columns |
| Tablet | 768px+ | Row header, skills 3 columns, projects 2 columns |
| Desktop | 1024px+ | Hero text left / image right, projects 3 columns |

Also tested on Chrome, Edge and Firefox.
